# 内容中台 v1.7.0

- 编导台新增爆款转绘工作区，可导入视频、重用已完成的反推结果、绑定角色场景道具图，并使用现有可灵通道逐镜生成或批量补齐
- 爆款转绘支持在工作区内逐镜选片、裁切、排序和试听，本机合成并预览、下载 MP4
- 爆款转绘角色卡新增三视图、四视图、出海描述和 MP3、WAV 音色绑定，沿用现有可灵生成通道
- 爆款转绘新增保留原台词的可编辑译文和批量分镜描述词，支持保留成功项并补齐缺失
- 爆款转绘集中显示参考视频、角色场景道具和逐镜制作列表，新增分镜状态筛选与默认视频参考方式
- 爆款转绘新增批量补齐实体图和分镜图，并支持采用前预览候选图片或视频
- 按授权前端包还原爆款转绘的深色工作区、历史项目、上传区、创作模式、素材卡和两种分镜布局
- 可在转绘工作区重命名项目、编辑风格和新增素材卡，并为现有可灵通道设置默认模型与画幅
- 爆款转绘显示原片预览、转绘分析服务商和分段进度，并统一为编导台样式
- 按授权前端包还原编导台字幕擦除工作区，支持批量上传、处理进度、历史记录、原片及结果预览与下载
- 支持本机移除独立字幕轨，或通过 OCR 识别底部硬字幕并修补对应画面
- 字幕擦除接入阿里云 IMS 普通版和私有 OSS，并提供编导台配置入口
- 编导台字幕擦除接入火山 AI MediaKit 标准版
- 双工作台可直达具体任务，本机自动分镜与按选中镜头发起 AI 商品识别拆分
- Windows 剪辑台在实际探测成功后提供 HEVC Alpha 导出。可保留透明度、原有音轨和帧率，并能回读透明画面。
- 统一字幕擦除与编导台的导航、浅色卡片和操作样式
- 修复爆款拆解把缺少数据、尚未实测和后续补证说明误判为已取得效果的错误。完整但顺序不同的分析维度由本机恢复展示顺序。
- 报告失败时显示具体步骤、字段和原因，区分基础结构、分析引用及复用骨架。自动纠正仍为一次。
- 错误摘要隐藏密钥及模型响应正文，保留已完成报告与原文。
- 爆款拆解的证据边界可引用本机口播或 OCR 中真实存在的数字，便于说明两种证据不一致。
- 无法核对的边界数字由本机改为核验说明，保留通过校验的分析和引用。分析正文继续检查无依据的时长和效果数据。
- 爆款拆解忽略引文附带的额外字段，按段落或帧编号逐字核对引用。
- 模型给出的画面引文经原帧核对。帧号不符时只采用本机唯一逐字匹配的帧，无法定位时将该项标为待补证，保留其他分析。
- 口播引文以本机原话为准，修正可唯一定位的段号，恢复因标点或空白不同而未通过的引文。
- 缺少可核对引文的分析项标为待补证。借鉴条目须有可定位的原话依据。
- 修复剪辑工程遮挡任务中心和更新日志，保留桌面浮层显示与焦点
- 修复 Windows 批量反推读写结果时偶发误报找不到结果或卡在处理中。短暂占用会有限重试，写入失败保留已落盘的报告，重试优先沿用原任务。
- 修复桌面更新把未确认的工作台状态视为空闲的问题。更新器启动失败时恢复工作台，保留已校验的更新包以便重试。
- 纠正剪映字幕回归夹具，分别验证默认保留可编辑字幕和显式关闭字幕。
- 画布读取失败时禁止编辑目标，切换失败时保留源画布修改。导出弹窗锁定键盘焦点，批量混剪快速退出时保存最新草稿。
- 导出可在准备与写入结束阶段取消。保留已有成品和独立字幕文件，排队或导出途中检测到工程变更时提示重新提交。Final Cut Pro 兼容旧设置并保留时间线字幕。
- 批量反推短暂写入失败后可以继续操作，单条继承实际使用整批设置。重启保留完整反推结果，脚本确认重试复用已保留任务并补齐未创建任务，临时读取失败后恢复轮询。
- 任务中心关闭或工作台切换后不执行旧跳转。小窗口保留更新结果，更新器在接管前确认准备状态，回滚保留原有历史版本记录。
- 团队 API 配置包可导入独立的阿里云转写条目，加密保存 Key 和 Workspace ID，并在导入后刷新当前窗口的转写状态。
- 含文字服务的配置包缺少阿里云转写时，预览和结果会提示缺项，保留已保存的转写配置。
- 修复 Windows HEVC Alpha 正式安装缺少编码组件，校验官方运行库并使用随程序分发的编码器
- 转绘素材导入、参考帧采纳和生成结果采用从排队起纳入忙碌状态，完成或失败后释放，避免更新中断文件写入。
- 已使用隔离桌面资料验证转绘入口、模拟可灵提交和任务恢复，以及三镜重排保留原声并导出 MP4。
- 使用隔离 Electron 和模拟服务完成五项操作验收，并验证老项目恢复台词、可灵音频槽与本机导出回归。
- 已验证宽屏和窄屏布局、分镜筛选、两种批量生图提交及候选预览，使用隔离样例与模拟可灵。
- 用隔离样例核对参考截图、桌面与窄屏布局，验证项目保存、候选预览、角色多视图和批量提交参数。可灵调用使用模拟回执。
- 包内缺少历史样式表，视觉对照使用包内组件和可取得的公开样式。编导台导航、模型及账号控件使用内容中台实现。
- 隔离开发版使用本地 MP4 验证上传、播放和拖动定位。使用模拟服务验收服务商与模型切换、刷新恢复、1/2 段显示 50%、失败分段重试及宽窄屏布局。
- 转绘分析可选已配置的服务商和模型，图片及视频生成继续走现有可灵通道。
- 用隔离开发版实测两条合成视频，覆盖硬字幕修补、独立字幕轨移除以及输出播放。批量、失败重试与窄屏点击通过浏览器验收。
- 桌面上传区、主按钮、说明和任务栏尺寸与离线参考对齐。历史样式表缺失，对照采用包内组件与留存的公开样式。
