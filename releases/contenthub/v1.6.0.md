# 内容中台 v1.6.0

- 编导台支持本机读取 Word 97–2003 .doc，可与 .docx 混合批量导入脚本。
- 本地镜头检测按画面邻帧判断边界，保留独立短镜头并按真实帧时间连续分段。
- 修复可编辑剪映草稿在变速片段分割处的源帧断点，左右段共用切点并保留原源出点
- 修复可编辑剪映草稿的极短分割和长串连续切片，逐接缝对齐并保留原源出点
- 修复编导台 DOCX 脚本正文定位和 Strict 格式兼容，细化无法读取时的提示。
- 修复批量确认时未单独打开的文档无法导入。
- 剪映草稿变速切点、极短片段和连续切片保留源帧、原声及字幕对齐
- 修复编导台批量确认漏报无法读取的文档并保留失败项状态
- 修复同轨叠放素材打断变速切片接缝识别，导出剪映草稿时保留正确的入出帧。
