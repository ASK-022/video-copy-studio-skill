# 内容中台完整离线版 1.1.1（资源 r1）

本版是编导台＋剪辑台的完整 Windows x64 安装包。程序版本 1.1.1 与独立资源版本 r1 分别管理；模型未变化时，后续程序发行继续引用同一份 r1，不重复上传模型。已有客户端检查更新只取程序增量，保留资料、Key 与模型。

## 新电脑首次安装

从 [完整桌面发行页](https://github.com/ASK-022/video-copy-studio-skill/releases/tag/contenthub-v1.1.1) 下载：

- `ContentHub-Offline-Install-v1.1.1.exe`。
- `ContentHub-v1.1.1-Install-01.zip` 至 `-06.zip`：6 个程序分包。
- `ContentHub-Resources-r1-01.zip` 至 `-25.zip`：25 个资源分包。
- 如果缺少微软 C++ x64 运行库，再下载同页 `VC_redist.x64.exe`。

将安装器与全部 31 个 ZIP 放在同一文件夹，无需手动解压。双击 Offline-Install 安装器，先选择程序目录以外的资源位置（建议 D/E 盘）；安装器核验分包及完整 SHA256、自动合并、离线解压并验证四组模型、浏览器和 FFmpeg。自检通过后自动进入标准程序安装向导，再选择程序安装位置。不要提前单独运行合并后的程序组件。

下载约 2.7 GB，资源解压约 4.26 GB，程序另需约 1 GB。请为分包、合并文件与安装合计预留至少 14 GB；同一资源目录一次只运行一个安装器。缺包和损坏会指出具体文件，重试复用已完成且通过校验的文件。

资源包含 SenseVoice Small、中文标点、时间对齐、OCR、Python/依赖、Playwright 浏览器与 FFmpeg。安装及本地转写不联网；AI 文案、公开链接解析与检查更新仍需联网和自己的服务配置。默认提供 CPU 通用运行环境；GPU 依赖可选，按需另行准备，模型权重继续复用。本包不含个人资料、历史项目或用户 Key。

维护者的单个完整 ZIP 可通过 U 盘、局域网或共享盘分发；解压后双击“开始安装内容中台.exe”。单个 ZIP 与小分包安装器对应不同内置清单，不能交叉混用。

## 已有客户端更新

已有 1.1.0：在顶部检查更新，下载完成后点击更新并重启，无需下载上述 25 个资源分包。更新清单仍是独立的 `releases/contenthub/latest.json`，验证签名与程序 SHA256；双工作台健康检查失败会恢复旧版本及资料元数据。已有模型与独立资源目录不进入程序更新包。

只有新增、更换模型或不兼容的运行资源时，才发布新的资源修订；不兼容时必须同步提升资源契约，不强行套用程序增量。`releases/contenthub/resources/r1.json` 是独立发行目录，记录完整资源及每个分包的校验值。它不是新的可执行更新指令，不替代现有签名程序清单。r1 资源固定在首次发布的 `contenthub-v1.1.1` 附件中，后续程序发行引用同一地址。
