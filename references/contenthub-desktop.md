以下为 v1.1.0 历史分包与资源说明：

内容中台完整桌面版 v1.1.0（编导台＋剪辑台，Windows x64）

一、安装
GitHub 与蓝奏云均下载全部 6 个 ContentHub-v1.1.0-Install-01.zip 至 -06.zip 分包和 ContentHub-Install-v1.1.0.exe，放在同一文件夹后双击安装助手。无需手动解压或拼接；助手逐包校验 SHA256，生成 ContentHub-Setup-v1.1.0-x64.exe 并打开可自选安装目录的标准安装向导。分包内是完整桌面安装器，与本地完整安装器功能相同。
无需自己安装 Git、Node.js 或系统 Python。当前发行包未附 Windows 代码签名；发布清单使用独立的 RSA-3072 签名，更新包另作 SHA256 校验。

二、首次转写资源与已有模型
程序已包含剪辑所需的 Chromium 和 FFmpeg，本地转写模型及 Python 资源单独保存。
已有文案工坊完整离线客户端或通过自检的资源目录，选择“选择已有资源”，选完整根目录即可复用，不重新下载模型。
没有资源则选择“下载并准备资源”，选择程序安装目录之外的位置。首次需下载数 GB。依赖优先清华镜像，失败回退华为镜像和官方源；浏览器优先 npmmirror；模型使用 ModelScope。基础 Python 和固定转写源码随准备程序附带，首次准备不依赖获取 GitHub 源码。
资源助手使用临时短路径处理 Windows 的长文件名安装问题，不改系统 PATH 或全局长路径设置。安装结束保存实际资源位置，临时盘符会释放。网络中断后可在相同资源目录继续准备。
本版本已用最终安装流程在全新目录、清除代理且禁用 pip 下载缓存的条件下完成下载，四组模型加载与推理通过，并完成 61 字实际转写。不同网络可能仍需切换线路或重试。

三、一键更新与失败回滚
客户端顶部点“检查更新”。启动后也会自动检查；找到新版后下载并校验程序增量，显示“更新并重启”。点击后，等待编导任务、素材导入、AI 任务和剪辑导出完成再切换。
更新清单由发布方签名；每个下载分片和重组 ZIP 均验证 SHA256。国内可直连的 CDN 版本清单优先，GitHub 作为备用。清单与下载分片的地址均固定在本仓库范围。
新版放入独立版本目录，旧程序保留。更新前独立复制资料元数据与加密 Key；切换后必须收到带随机凭据的双工作台启动成功回执，才确认更新。任一工作台启动失败、提前退出或超过检查时间，将恢复旧版本和元数据并重新打开。意外中断的更新会在下次启动时恢复或确认已完成的健康版本。
用户资料、Key、项目和模型不打进更新包。模型不随更新重新下载。已保存的资料保留；尚未提交的页面输入请先保存。
此完整桌面版与 VideoCopyStudio v1.2.0 文案客户端使用独立的发布标记和版本清单，不能交叉套包。旧的完整桌面测试包 v1.0.0 尚无更新入口，首次请退出并卸载旧测试程序后安装 v1.1.0，保留用户资料及外部模型目录，之后使用客户端内更新。早期测试卸载器存在跨盘覆盖问题，本版本安装器已修复。资源契约不兼容或无适配增量时，客户端会要求完整安装器。

四、资料位置与排错
默认用户资料：%APPDATA%\内容中台；编导资料在其 director-data，剪辑服务配置在 studio。项目和导出默认位于“文档\内容中台”，以客户端实际设置为准。Key 使用当前 Windows 账号加密保存，换电脑或账号时需要重新填写。
版本程序在所选安装目录的 versions，当前版本指针为 current.json。不要手动移动内部版本文件，也不要将模型或个人资料放入程序安装目录。
更新结果在用户资料目录 desktop-update-result.json，更新日志为 logs\desktop-updater.log，启动日志为 logs\desktop-launch.log，编导日志为 logs\director-service.log。资源准备日志在所选资源目录 resource-setup.log、bootstrap.log、models.log。
回滚用的旧程序与资料元数据备份保留在本机，不上传云端。更新需要额外可用空间。云端下载文件只包含软件与说明，不包含任何用户 Key、资料或模型缓存。
