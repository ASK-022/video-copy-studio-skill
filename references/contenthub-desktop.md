# 内容中台完整桌面版 v1.2.0：安装与更新

[GitHub 正式发布页](https://github.com/ASK-022/video-copy-studio-skill/releases/tag/contenthub-v1.2.0)提供 `ContentHub-Setup-v1.2.0-x64.exe` 与 SHA256 校验表。本版来自已验收的 1.2.0-dev.18：14 组门禁、冻结双工作台、默认自动模式实际转写及真实升级／强制失败回滚均通过，绑定当前源码和安装器。本次先提供 GitHub 正式更新；蓝奏云新版安装包待补。资源 r1 的首次远端分发尚未全部就绪，新电脑仍需单独准备转写资源或使用完整本地离线资源包。

适用于 Windows 10／11 x64，包含编导台和剪辑台。完整桌面版发布标签为 `contenthub-v1.2.0`，与 VideoCopyStudio 文案客户端 `v1.2.1` 的安装器、资源登记和更新清单分别维护。

## 安装

1. 从[本版 GitHub 发布页](https://github.com/ASK-022/video-copy-studio-skill/releases/tag/contenthub-v1.2.0)下载 `ContentHub-Setup-v1.2.0-x64.exe`，对照同页 SHA256 校验表。
2. 双击安装器，选择安装目录并完成安装。无需先安装 Git、Node.js 或系统 Python。
3. 已有通过自检的转写资源，在客户端选择“选择已有资源”，选完整资源根目录。资源契约 r1 未变化，已有模型继续复用。没有资源的新电脑需运行资源准备流程，首次下载数 GB 后以加载及转写自检成功为准；本版程序 EXE 不包含完整转写模型。
4. 在设置里配置自己的服务，或按下方步骤导入团队 API 包。本地音视频转写不需要 AI Key；AI 纠错、画面理解、公开链接解析及可灵生成按各自服务要求配置。

当前程序未附 Windows 代码签名；程序更新清单使用内置发布公钥验证 RSA 签名，下载的分片及组合 ZIP 另校验 SHA256。

## 已有完整桌面版一键更新

v1.1.0／v1.1.1 用户先保存页面中尚未提交的编辑，等待编导、AI、导入及剪辑任务结束，再点顶部“检查更新”。下载和摘要校验完成后点“更新并重启”。客户端根据原版本选择程序增量，名称含 `delta`／`part` 的文件由客户端处理，无需手工解压。

程序写入独立版本目录并保留旧版；切换后编导台与剪辑台都须通过启动健康检查。启动失败会恢复旧程序和备份的资料元数据；更新意外中断时，下次启动执行恢复检查。资料、项目、当前用户加密 Key 及模型不随程序增量覆盖。

模型未变时不重新下载。GPU 环境按需准备，程序更新不强制下载 CUDA 依赖。资源契约不兼容或无适配增量时，请使用完整安装器，不要手工套用其他产品或版本的增量包。

更新清单镜像：[Fastly CDN](https://fastly.jsdelivr.net/gh/ASK-022/video-copy-studio-skill@main/releases/contenthub/latest.json)、[备用 CDN](https://gcore.jsdelivr.net/gh/ASK-022/video-copy-studio-skill@main/releases/contenthub/latest.json)，并回退 [GitHub 原始清单](https://raw.githubusercontent.com/ASK-022/video-copy-studio-skill/main/releases/contenthub/latest.json)。客户端只接受签名有效的清单；不同运营商和镜像同步速度可能不同。更新检查不发送素材、稿件或 Key。

## 团队 API 配置包一键导入

打开“设置 → 服务商 → 团队 API 配置包”，选择团队提供的 ZIP 或 JSON，检查预览中的服务商和模型，再点“导入并启用”。兼容已有 `contenthub-local-api-keys/v1` 密钥包；支持 AI、TikHub、Cue 及飞书配置，具体以包内内容为准。导入后使用当前 Windows 用户重新加密，重复导入会更新匹配的配置，不增加重复服务。

包不合法、预览过期、配置发生变化或保存失败时会提示错误；重新选择并预览后再导入。不支持的服务会拒绝整个包，避免只导入一部分。可灵 CLI 使用官方登录授权，不能用此 API 包替代。

团队密钥包含敏感信息，请在团队认可的私密渠道传递。不要上传 GitHub、蓝奏云软件公开目录或反馈截图。不要直接把另一台电脑的加密配置文件复制过来。软件、安装器、更新分片和公共说明不包含个人或团队 Key。

## v1.2.0 更新内容与验收

- 编导台：批量视频解析与 Grok 画面反推、分阶段进度、统一任务中心、取消与重试；重试复用已有下载和转写。提示词反推支持选区整体平移、端点调整和保存恢复；创作分区的顶部宣传区已简化。
- 剪辑台：创作画布的素材／提示词节点、连线、框选与镜头分组、预览定位、自动保存恢复和工作流模板；图片、视频和音频可从资源管理器拖入。画布 AI 方案先预览再确认，可灵使用官方授权并保留生成任务及导入结果。
- 配置与版本：团队 API 包导入和当前用户加密；开发／正式版本分别编号并展示更新日志；候选包绑定当前源码和测试回执。
- 自动转写修复：自动模式遇到已识别的 CUDA 张量设备不匹配时尝试 CPU；显式选择 GPU 和普通非 CUDA 错误保持原有行为。
- 最终候选检查：14 组完整门禁通过，选区交互 9 项和 Prompt 服务 23 项通过；冻结编导台与剪辑台均就绪，合成中文音频实际转写 46 字；假 API 包三服务导入、重复导入去重及加密保存通过。
- 默认自动模式实测：首次已从本地离线包在全新目录准备 r1 资源，本次复用该资源；GPU 遇到设备不匹配后自动重试 CPU，完成 46 字转写，22 个模型文件未变。编导服务、GPU 探测、GPU ASR 和 CPU ASR 的实际 Python PID 均关联网络隔离记录，转写阶段受监测 Python 外联尝试为 0；该结果不覆盖 Electron／Node 网络，也不代表首次网络下载已测通。
- 实际更新与回滚：通过冻结执行器从 v1.1.1 升级到 v1.2.0，并在另一次测试中强制新版启动失败、恢复 v1.1.1；两次均保留 10 个合成资料文件和 22 个模型，测试加密 Key 可解密，项目与已存任务可读。

内容中台完整桌面版 v1.1.0（编导台＋剪辑台，Windows x64）

一、安装
GitHub 与蓝奏云均下载全部 6 个 ContentHub-v1.1.0-Install-01.zip 至 -06.zip 分包和 ContentHub-Install-v1.1.0.exe，放在同一文件夹后双击安装助手。无需手动解压或拼接；助手逐包校验 SHA256，生成 ContentHub-Setup-v1.1.0-x64.exe 并打开可自选安装目录的标准安装向导。分包内是完整桌面安装器，与本地完整安装器功能相同。
无需自己安装 Git、Node.js 或系统 Python。当前发行包未附 Windows 代码签名；发布清单使用独立的 RSA-3072 签名，更新包另作 SHA256 校验。

二、首次转写资源与已有模型
程序已包含剪辑所需的 Chromium 和 FFmpeg，本地转写模型及 Python 资源单独保存。
已有文案工坊完整离线客户端或通过自检的资源目录，选择“选择已有资源”，选完整根目录即可复用，不重新下载模型。
没有资源则选择“下载并准备资源”，选择程序安装目录之外的位置。首次需下载数 GB。依赖优先清华镜像，失败回退华为镜像和官方源；浏览器优先 npmmirror；模型使用 ModelScope。基础 Python 和固定转写源码随准备程序附带，首次准备不依赖获取 GitHub 源码。
资源助手使用临时短路径处理 Windows 的长文件名安装问题，不改系统 PATH 或全局长路径设置。安装结束保存实际资源位置，临时盘符会释放。网络中断后可在相同资源目录继续准备。
本版本已用最终安装流程在全新目录、清除代理且禁用 pip 下载缓存的条件下完成下载，四组模型加载与推理通过，并完成 61 字实际转写。不同网络可能仍需切换线路或重试。

三、一键更新与失败回滚
客户端顶部点“检查更新”。启动后也会自动检查；找到新版后下载并校验程序增量，显示“更新并重启”。点击后，等待编导任务、素材导入、AI 任务和剪辑导出完成再切换。
更新清单由发布方签名；每个下载分片和重组 ZIP 均验证 SHA256。国内可直连的 CDN 版本清单优先，GitHub 作为备用。清单与下载分片的地址均固定在本仓库范围。
新版放入独立版本目录，旧程序保留。更新前独立复制资料元数据与加密 Key；切换后必须收到带随机凭据的双工作台启动成功回执，才确认更新。任一工作台启动失败、提前退出或超过检查时间，将恢复旧版本和元数据并重新打开。意外中断的更新会在下次启动时恢复或确认已完成的健康版本。
用户资料、Key、项目和模型不打进更新包。模型不随更新重新下载。已保存的资料保留；尚未提交的页面输入请先保存。
此完整桌面版与 VideoCopyStudio v1.2.0 文案客户端使用独立的发布标记和版本清单，不能交叉套包。旧的完整桌面测试包 v1.0.0 尚无更新入口，首次请退出并卸载旧测试程序后安装 v1.1.0，保留用户资料及外部模型目录，之后使用客户端内更新。早期测试卸载器存在跨盘覆盖问题，本版本安装器已修复。资源契约不兼容或无适配增量时，客户端会要求完整安装器。

四、资料位置与排错
默认用户资料：%APPDATA%\内容中台；编导资料在其 director-data，剪辑服务配置在 studio。项目和导出默认位于“文档\内容中台”，以客户端实际设置为准。Key 使用当前 Windows 账号加密保存，换电脑或账号时需要重新填写。
版本程序在所选安装目录的 versions，当前版本指针为 current.json。不要手动移动内部版本文件，也不要将模型或个人资料放入程序安装目录。
更新结果在用户资料目录 desktop-update-result.json，更新日志为 logs\desktop-updater.log，启动日志为 logs\desktop-launch.log，编导日志为 logs\director-service.log。资源准备日志在所选资源目录 resource-setup.log、bootstrap.log、models.log。
回滚用的旧程序与资料元数据备份保留在本机，不上传云端。更新需要额外可用空间。云端下载文件只包含软件与说明，不包含任何用户 Key、资料或模型缓存。
