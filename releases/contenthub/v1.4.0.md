# 内容中台 v1.4.0

- 新增原位素材分类库与口播语境检索，减少同场景和加注镜头重复
- 提示词反推自动提取角色、场景、道具，支持跨镜头改名、关键词预览、替换与撤销，草稿用于复制和导出。
- 单条与批量反推按所选范围每 15 秒输出一段逐镜头 Seedance 提示词，尾段保留实际时长，失败段可单独重试。
- 开发版以受管实例启动编导服务，正常退出时平滑关闭空闲服务，重启时加载当前代码。
- 提示词反推明确显示 Seedance 生成入口、15 秒分段预览和旧版报告说明。前端确认服务支持 Seedance 后开放生成。
- 历史反推结果常驻旧版提示，编导服务统一用 Seedance 处理新反推
- 桌面反推导航按开发版本加载页面，编导台刷新快捷键刷新当前工作台
- 取消 Seedance 提示词反推的 12 帧上限，按选段时长每秒抽帧
- 内置浏览器诊断日志写入用户资料目录并从程序包排除
- 内置浏览器在用户资料目录运行，隔离 Windows 子进程诊断文件
- 缩短浏览器缓存路径，兼容较深的 Windows 用户资料目录
- 正式基线更新为1.3.2；五处审查修复已从1.3.1独立热修复发布，素材库功能继续开发，尚未通过本批次正式门禁。
