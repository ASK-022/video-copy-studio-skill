# 内容中台 v1.2.3（编导台＋剪辑台）

本版合入最新剪辑与智能混剪功能，并保留此前全部待发布开发批次。

- AI 换产品从实际时间线片段取得选段，支持原视频、产品素材引用及后台识别；生成结果可回收到工程、采用到时间线或恢复原片，保留原声与编辑记录。
- 智能混剪保留可编辑时间线、候选与确认步骤；单条口播预览优先播放原文件。
- 创作画布支持节点内编辑、媒体播放及素材引用；保留剪辑快捷键预设、聊天面板折叠和版本历史。
- 编导台保留文案、拆解、选段导出、案例库与团队 API 配置包入口；云转写配置独立于文字 AI 服务。
- 修复完整桌面安装布局下时间线模块的依赖解析，避免源码运行正常而安装程序无法启动。

首次安装下载 **ContentHub-Setup-v1.2.3-x64.exe**，可选择安装目录。新电脑需要完整离线资源时，另下载本版离线向导、微软运行库及原 r1 的 25 个资源 ZIP，按离线说明安装。已有 r1 模型与运行资源直接复用，不必重新下载。

已有 v1.1.0、v1.1.1、v1.2.0 或 v1.2.1 完整桌面版，可在客户端检查更新并重启。程序更新保留资料、加密 Key、项目和模型；新版本启动失败时恢复旧版本。名称含 delta／part 的附件由更新器使用，首次安装只需完整 EXE。

验证包括当前源码 60 组检查、同源程序双工作台启动、实际合成语音本地转写、模型复用、假 Key 配置包导入／去重／加密、四个旧版本的签名更新下载与合并，以及 v1.1.1 的实际升级和强制启动失败回滚。飞书案例功能本轮核对对应源码一致、当前官方 CLI 与授权边界，未重新提交云写入或云回读；未提交新的付费生成或真实音频云转写。

AI、云转写、飞书和公开链接服务仍使用各用户自己的配置与授权。公开软件附件不含个人 Key、CLI 登录态、生产媒体或项目。私人 API 配置包另行本机交付。

本轮使用 GitHub 完整桌面发行通道，蓝奏云后补；独立文案客户端及 Agent Skill 的 latest 发布保持不变。
